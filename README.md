# Cartão Digital - União Embalagens

Um cartão de visitas digital e interativo desenvolvido para facilitar o contato e direcionamento de clientes para os canais de atendimento da empresa.

## 🚀 Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript

## ✨ Funcionalidades
* Links de redirecionamento direto para WhatsApp e Instagram.
* Interface responsiva, adaptada para telas de celulares e computadores.
